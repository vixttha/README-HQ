# README HQ trial on Provenistem

This trial applied the [README HQ v0.0.6 writing guide](https://github.com/vixttha/README-HQ/blob/f50e3749dab90ddfe35894284d1660097a1fb1a8/README-GUIDE.md) to the public `Provenistem` branch. The [starting revision](https://github.com/vixttha/README-HQ/commit/eac87d6a10899e96d4851fbbced308432c3ade5a) opened on the host project's landing page and placed the tracker one directory down.

| Reader task | Expected result |
| --- | --- |
| Open the branch homepage | The page identifies Provenistem and links to Features and Ideas at the branch root. |
| Find a feature available now | The Features index leads to the version archive record and its pinned source. Draft work and proposals are labeled separately. |
| Recover a captured idea from a fresh checkout | The Ideas index leads to `IDEA-000008` and its date, origin, purpose, and current state. |
| Start a new record | Each index leads to its starter form, and the homepage explains the next ID and which index to update. |

The trial records README HQ's capabilities and planning ideas. The capture example is a new idea from the tracker design discussion on November 19, 2026.

## Results

- The branch tree contains the Provenistem landing page, both record libraries, starter forms, and these trial notes.
- The original records and starter files kept their bytes. The new dated idea is reachable from the Ideas index.
- Both available feature records appear before the separately labeled draft record. The five planned or proposed records are on their own page.
- The Provenistem v0.0.2 validator accepted 8 ideas and 8 features. Both starter forms passed their schema checks, and all 32 local documentation links resolved.
