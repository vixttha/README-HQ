**Use when.** Commands or syntax differ across supported operating systems or shells.

**Reader task.** Quickstart and adoption.

**Practice.** Label POSIX and PowerShell paths where their commands differ.

**Example (illustrative).** Show PowerShell and bash commands in separate blocks labeled by platform.

**Result to check.** Each block works in its own shell from the same intended starting state.
