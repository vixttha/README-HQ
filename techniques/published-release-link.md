# Published release link

**Use when.** A reader needs the official published assets for a specific version.

**Reader task.** Verification and trust.

**Practice.** Give a direct path to the release named in the README and its release notes.

**Example (illustrative).** Link v2.4 to its release page and name where the supported download is listed.

**Result to check.** The link resolves to the intended published version with the stated assets.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
