# One prominent first action

**Use when.** Several links compete for a new reader’s attention.

**Reader task.** Quickstart and adoption.

**Practice.** Lead with a recognizable task such as play, try, install, or adopt.

**Example (illustrative).** Start with the Quickstart link, then place the API and build references below it.

**Result to check.** A first-time reader finds the intended next action without scanning every section.
