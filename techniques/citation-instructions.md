# Citation instructions

**Use when.** Researchers need a maintained source for attributing a release.

**Reader task.** Handoff and maintenance.

**Practice.** Point researchers to the maintained citation metadata where appropriate.

**Example (illustrative).** Link CITATION.cff and identify which citation to use for a particular release.

**Result to check.** A reader can cite the matching release with the maintained authorship and identifier.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Zenodo’s version-specific records and citations](https://help.zenodo.org/docs/deposit/manage-versions/)
