# Route readers to editable designs and manufacturing exports

**Use when.** Designers and builders need different versions of the same design.

**Reader task.** Handoff and maintenance.

**Practice.** Give separate links to the preferred files for modifying the design, files prepared for fabrication, and human-readable drawings where provided. Label the toolchain and revision that produced the exports.

**Example (illustrative).** Link the editable CAD project and label the generated manufacturing archives.

**Result to check.** A designer can find the source, and a fabricator can choose the correct output.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [OSHWA design-file guidance](https://oshwa.org/resources/sharing-best-practices/)
