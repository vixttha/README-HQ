# Consistent terms

**Use when.** Several terms are used for the same concept across docs and UI.

**Reader task.** Navigation and accessibility.

**Practice.** Use the same names for actions and objects as the code, UI, and linked instructions.

**Example (illustrative).** Call the same product object a Workspace throughout navigation, examples, and screenshots.

**Result to check.** Search the rendered guide and check that one concept consistently uses its chosen term.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
