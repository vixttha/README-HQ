# Put a practice task before its worked solution

**Use when.** A tutorial reader should practice a skill before seeing an answer.

**Reader task.** First result and recovery.

**Practice.** When the README is also a learning guide, give readers a short task and a way to check their attempt. Put the worked answer behind a labeled section or link. The Carpentries uses separate challenge and solution blocks.

**Example (illustrative).** Ask the reader to change one option, then place the worked solution under a separate heading.

**Result to check.** The task is solvable using the preceding material and the answer is easy to locate afterward.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [The Carpentries exercise format](https://carpentries.github.io/lesson-development-training/instructor/lesson-content.html#adding-exercises)
