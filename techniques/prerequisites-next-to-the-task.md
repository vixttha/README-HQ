# Prerequisites next to the task

**Use when.** A command assumes an installed tool, a credential, or a running service.

**Reader task.** Quickstart and adoption.

**Practice.** Name tools, versions, access, and prior setup before any commands depend on them.

**Example (illustrative).** Put the database version and sample credentials setup directly above the import command.

**Result to check.** A clean environment can follow the task without discovering a missing dependency mid-run.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
