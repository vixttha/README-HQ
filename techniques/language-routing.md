# Language routing

**Use when.** A README is maintained in multiple languages.

**Reader task.** Navigation and accessibility.

**Practice.** Link translated docs and make the expected language clear.

**Example (illustrative).** Show English, Español, and 日本語 links in the translation entry point.

**Result to check.** Each language link resolves to the intended edition and offers a route back.
