# Safe configuration example

**Use when.** Readers need a working configuration without including credentials or production defaults.

**Reader task.** Quickstart and adoption.

**Practice.** Use labeled placeholders and explain where values belong.

**Example (illustrative).** Use a local test endpoint and a named environment variable for the API token.

**Result to check.** The example works with test values and contains no real credentials.
