# Snapshot source identity

**Use when.** A historical README or visual must be traceable to exact source bytes.

**Reader task.** Verification and trust.

**Practice.** Record the origin and digest of frozen README or asset bytes when exact archival identity matters.

**Example (illustrative).** Record the original README’s commit, path, and SHA-256 beside the frozen copy.

**Result to check.** The stored bytes match the recorded digest and the source location resolves.
