# Send readers to docs for their installed version

**Use when.** Instructions differ across supported installed releases.

**Reader task.** Navigation and accessibility.

**Practice.** Label stable and development docs links so readers can match them to the version they are using. A branch README can link multiple editions if its audience spans supported releases.

**Example (illustrative).** Choose the docs version from the version printed by the executable.

**Result to check.** A user on either of two supported versions reaches the matching instructions.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Read the Docs version routing](https://docs.readthedocs.com/platform/stable/versions.html) · [Godot’s development docs notice](https://docs.godotengine.org/en/latest/getting_started/step_by_step/index.html)
