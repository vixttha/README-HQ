# Offer an importable API request collection

**Use when.** An API example has multiple requests or variables that a client can import.

**Reader task.** Quickstart and adoption.

**Practice.** Link a reusable request collection so readers can run the same requests in their API client. Identify the target environment and show which values they need to supply locally.

**Example (illustrative).** Link an importable collection and list the environment variables needed for its first request.

**Result to check.** After import, a reader can run the sample in a clean client configuration.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Postman’s README integration](https://learning.postman.com/docs/publishing-your-api/run-in-postman/creating-run-button/)
