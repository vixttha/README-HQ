# Lightweight link verification

**Use when.** Relative links, fragments, or evidence URLs can drift as files move.

**Reader task.** Verification and trust.

**Practice.** Check that critical relative targets and anchors resolve at the claimed revision.

**Example (illustrative).** Check local links and heading fragments on every documentation change.

**Result to check.** A broken example link fails the check and the diagnostic names its source file and target.
