# Descriptive link labels

**Use when.** A generic link label would make the destination unclear out of context.

**Reader task.** Navigation and accessibility.

**Practice.** Use text that tells the reader where the link goes or what it does.

**Example (illustrative).** Use “Windows installation guide” as the link label.

**Result to check.** The destination remains clear when links are read out of paragraph order.
