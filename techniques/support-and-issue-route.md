# Support and issue route

**Use when.** User questions, bugs, and other requests have different destinations.

**Reader task.** Handoff and maintenance.

**Practice.** Tell readers where to report a bug or ask for help and what evidence to include.

**Example (illustrative).** Send usage questions to Discussions and reproducible bugs to the issue form.

**Result to check.** Each common support need has a working destination with its expected inputs.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
