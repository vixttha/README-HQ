# Provide a starter control map

**Use when.** A game or interactive demo needs input mappings before the first action.

**Reader task.** Quickstart and adoption.

**Practice.** List the actions a player needs in the first minute and map them to each supported input type. Point to remapping settings where they exist.

**Example (illustrative).** Map Move, Confirm, and Back to the default keyboard and controller inputs.

**Result to check.** A new player can complete the intro using each supported input mode.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Years to Spare control table](https://github.com/r6mez/Years-to-Spare/blob/55dc4527b475efa3c030a7c42ecf265bddf3d0c8/README.md#L83-L95) · [Game Accessibility Guidelines on remapping](https://gameaccessibilityguidelines.com/allow-controls-to-be-remapped-reconfigured/)
