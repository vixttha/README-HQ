# Roadmap pointer

**Use when.** Readers need to distinguish current scope from future plans.

**Reader task.** Purpose and audience.

**Practice.** Link planned work to a maintained roadmap and distinguish it from available features.

**Example (illustrative).** Planned support for team accounts lives in the roadmap. The current release supports one account per workspace.

**Result to check.** A reader can distinguish a planned feature from a current capability.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
