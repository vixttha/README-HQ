# Give a deprecation notice a replacement and timeline

**Use when.** A public command, API, or package is being retired in favor of another.

**Reader task.** Handoff and maintenance.

**Practice.** Name the affected interface, link the replacement or migration route, and distinguish the deprecation date from any planned retirement date. Link the authoritative policy when it governs multiple interfaces.

**Example (illustrative).** Name the deprecation date, supported replacement, and migration guide.

**Result to check.** A reader can tell when to move and which supported path to take.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [IETF Deprecation header field](https://www.rfc-editor.org/rfc/rfc9745.html) · [IETF Sunset header field](https://www.rfc-editor.org/rfc/rfc8594.html)
