# Attribution and data provenance

**Use when.** Documentation or examples rely on someone else’s data or assets.

**Reader task.** Handoff and maintenance.

**Practice.** Link the source and terms for material external assets or datasets.

**Example (illustrative).** Name the provider and version of the sample dataset and link its usage terms.

**Result to check.** A reader can identify the dataset’s origin, revision, and governing terms.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
