# Turn an archived README into a handoff

**Use when.** An archived repo remains visible and readers need an onward route.

**Reader task.** Handoff and maintenance.

**Practice.** Put the maintained successor and new project name, if any, at the top of the archive. State what remains accessible at the old location. Prisma Next explains its move and archive status before its historical README content.

**Example (illustrative).** Label the project archived and point to the maintained replacement and final supported release.

**Result to check.** A reader opening the old homepage can find the successor and the last usable version.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Prisma Next archive handoff](https://github.com/prisma/prisma-next/blob/55458c441d2cf452028c22eed21370447720840a/README.md#L1-L10)
