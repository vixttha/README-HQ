# Label ownership of installation channels

**Use when.** Official and community installation channels coexist.

**Reader task.** Quickstart and adoption.

**Practice.** Identify who maintains and supports each package or installer so readers know where to report installation problems. GitHub CLI links community-supported routes separately.

**Example (illustrative).** Label project-built binaries and community packages with the maintainer and support route.

**Result to check.** Each install link identifies who publishes and supports that distribution.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.
