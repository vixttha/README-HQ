# Scope boundaries

**Use when.** Readers could reasonably expect unsupported platforms or tasks to work.

**Reader task.** Purpose and audience.

**Practice.** Call out material limitations or environments outside the supported scope.

**Example (illustrative).** Runs on desktop Linux and Windows. Browser and mobile use are outside the supported scope.

**Result to check.** A reader can tell whether their environment or task fits before installing.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
