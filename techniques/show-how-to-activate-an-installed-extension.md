# Show how to activate an installed extension

**Use when.** An extension needs activation after installation.

**Reader task.** First result and recovery.

**Practice.** Name the first command, view, or event that activates the extension and the behavior a reader should see. VS Code distinguishes installing an extension from activating it on a matching event.

**Example (illustrative).** After installing the plugin, enable it in the editor and confirm the command appears.

**Result to check.** A fresh install can activate the plugin and see the documented success cue.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.
