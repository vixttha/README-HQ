# Architecture or flow diagram

**Use when.** A system or workflow is hard to follow from prose alone.

**Reader task.** Demos and visuals.

**Practice.** Show component relationships or the order of steps.

**Example (illustrative).** Draw the upload, parser, and export stages with one sentence explaining the direction of data.

**Result to check.** The diagram agrees with the actual sequence and the text path explains it without the image.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
