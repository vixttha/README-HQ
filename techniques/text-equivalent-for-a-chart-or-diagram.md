# Text equivalent for a chart or diagram

**Use when.** A chart or diagram carries values, relationships, or trends used in the text.

**Reader task.** Demos and visuals.

**Practice.** Put essential values, conclusions, or relationships in surrounding text.

**Example (illustrative).** Below the chart, list the two measured values and state the trend the chart illustrates.

**Result to check.** Readers using plain text can recover the conclusion and numbers.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
