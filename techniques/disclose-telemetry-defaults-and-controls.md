# Disclose telemetry defaults and controls

**Use when.** Installation or normal use can collect or transmit usage data.

**Reader task.** Purpose and audience.

**Practice.** Name the data a tool collects, the default participation state, and how to view or change the setting. Next.js documents the data collected and its opt-out control.

**Example (illustrative).** Crash reports are disabled by default. Enable them in Settings and review which fields are sent.

**Result to check.** A clean install matches the stated default and the documented control changes it.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Next.js telemetry documentation](https://nextjs.org/telemetry)
