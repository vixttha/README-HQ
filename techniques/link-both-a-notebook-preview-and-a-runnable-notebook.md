# Link both a notebook preview and a runnable notebook

**Use when.** A notebook has value both as readable output and as an executable walkthrough.

**Reader task.** Demos and visuals.

**Practice.** Label the link for inspecting saved results and the link for launching the notebook at the corresponding revision. GitHub renders notebooks statically, while Binder can open a particular notebook for execution.

**Example (illustrative).** Preview the notebook on GitHub, or open the same revision in a notebook runtime to execute it.

**Result to check.** Both routes use the same notebook revision and the runnable route reaches the first result.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [GitHub notebook rendering](https://docs.github.com/en/repositories/working-with-files/using-files/working-with-non-code-files#working-with-jupyter-notebook-files-on-github) · [Binder notebook links](https://mybinder.readthedocs.io/en/latest/howto/user_interface.html)
