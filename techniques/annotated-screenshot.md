# Annotated screenshot

**Use when.** A useful screenshot has important controls or results that could be missed.

**Reader task.** Demos and visuals.

**Practice.** Identify the controls or evidence a reader needs to notice.

**Example (illustrative).** Label the import button and the resulting row count on the screenshot.

**Result to check.** Each annotation names a visible control or result and stays legible at README width.
