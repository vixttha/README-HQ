# Track the source revision of translations

**Use when.** Translations can be published or updated separately from the source language.

**Reader task.** Navigation and accessibility.

**Practice.** Link a translated README to its original and record which revision or release it follows. This lets maintainers identify what needs updating and readers find the source text when needed. Kubernetes documents its upstream-first translation workflow.

**Example (illustrative).** The French guide links to the English revision it translates.

**Result to check.** A maintainer can compare that revision with current source text and find stale translation areas.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Kubernetes localization workflow](https://kubernetes.io/docs/contribute/localization/)
