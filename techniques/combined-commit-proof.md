# Combined-commit proof

**Use when.** Changes were tested individually and also need integration evidence.

**Reader task.** Verification and trust.

**Practice.** Tie a merge-readiness claim to tests on the exact combined content.

**Example (illustrative).** Report tests run on the candidate containing both changes and the target branch revision.

**Result to check.** The receipt identifies the exact combined commit and covers the stated integration path.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
