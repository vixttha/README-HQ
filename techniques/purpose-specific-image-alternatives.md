# Write image alternatives for their purpose

**Use when.** An image communicates information, provides a link, or decorates the README.

**Problem.** A screenshot, linked image, or diagram may be the only source of an instruction or explanation.

**Practice.** Summarize an informative image’s relevant content. Give a decorative image empty alt text when appropriate. If the image supplies a link’s label, describe the destination or action. Provide an accompanying text equivalent for a complex diagram.

**Example.** AlderVale’s pinned README describes what is visible in the annotated campus screenshot and separately captions the scene and build.

**Limits.** Write alternatives in context. An image with sufficient nearby explanatory text can need less in its alt attribute. Preserve all essential instructions in text.

**Result to check.** Read the page with images unavailable and follow any image-only links. Check that you can still identify the information and destinations needed for the task.
