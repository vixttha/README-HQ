# Independent version lines

**Use when.** A product, template, dataset, or docs set ships on its own release cadence.

**Reader task.** Handoff and maintenance.

**Practice.** Name the product, README, or collection beside each version when their release lines differ.

**Example (illustrative).** Label the tool release and its documentation-template revision wherever both appear.

**Result to check.** A reader can identify which version belongs to each lifecycle.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
