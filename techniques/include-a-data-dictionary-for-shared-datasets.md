# Include a data dictionary for shared datasets

**Use when.** A dataset includes fields or values that are hard to interpret from names alone.

**Reader task.** Handoff and maintenance.

**Practice.** Explain file relationships, field names, units, and missing-value codes so another person can interpret the data. Link the full dictionary when it needs its own file.

**Example (illustrative).** Document row meaning, field units, join keys, and missing-value codes beside the data.

**Result to check.** A reader can correctly interpret a sample row and join it to its companion table.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Cornell’s research-data README guide](https://data.research.cornell.edu/data-management/sharing/readme/)
