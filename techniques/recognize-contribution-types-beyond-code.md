# Recognize contribution types beyond code

**Use when.** Help beyond code is welcome and needs recognizable entry points.

**Reader task.** Handoff and maintenance.

**Practice.** Label what people contributed, such as documentation, design, translation, or testing, in the README or linked credits. The All Contributors specification describes these recognitions and a generated contributor table.

**Example (illustrative).** List translation, bug triage, design, and testing alongside code contributions with links to start.

**Result to check.** Each listed contribution type has a real entry point and a response route.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [All Contributors specification](https://allcontributors.org/en/project/specification/requirements/)
