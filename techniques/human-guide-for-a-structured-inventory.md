# Human guide for a structured inventory

**Use when.** A structured inventory is easy for software to parse and lacks a human entry point.

**Reader task.** Handoff and maintenance.

**Practice.** Pair a machine-readable manifest with an explanation of its reader-facing purpose.

**Example (illustrative).** Link the inventory manifest and explain how to find the record for a supported artifact.

**Result to check.** A person can select the correct record using the documented structure and identifiers.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
