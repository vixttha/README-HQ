# Map each claim to the check that can reproduce it

**Use when.** A release, paper, or benchmark makes several separately checkable claims.

**Reader task.** Verification and trust.

**Practice.** Pair the claim or reported result with its command, expected outcome, and the data it produces. Label claims that fall outside the reproduction instructions.

**Example (illustrative).** For Figure 2, list the plotting command, output filename, and settings used.

**Result to check.** A reader can produce the specified result and relate it to the exact claim.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [SPIN reproduction guidance](https://spin-web.github.io/SPIN2026/artifacts) · [USENIX artifact appendix guidance](https://www.usenix.org/conference/usenixsecurity22/artifact-appendix-guidelines)
