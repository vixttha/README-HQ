# Table of contents or jump links

**Use when.** A long README has several independent tasks readers need to revisit.

**Reader task.** Navigation and accessibility.

**Practice.** Expose major sections when the page is long enough to need them.

**Example (illustrative).** Link Install, Verify, and Troubleshoot at the top of a long README.

**Result to check.** Every jump link lands on its matching rendered heading.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
