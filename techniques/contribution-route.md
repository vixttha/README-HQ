# Contribution route

**Use when.** A new contributor needs the submission process and a first task.

**Reader task.** Handoff and maintenance.

**Practice.** Point to contribution rules, issue templates, and where work is reviewed.

**Example (illustrative).** Link to contribution instructions and name how to find an approachable open task.

**Result to check.** A new contributor can locate both the workflow and a suitable entry point.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [Open Source Guides](https://opensource.guide/starting-a-project/)
