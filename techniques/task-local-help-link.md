# Task-local help link

**Use when.** Someone at a specific step needs a narrow reference or recovery path.

**Reader task.** Navigation and accessibility.

**Practice.** Put the relevant support path beside a high-friction step.

**Example (illustrative).** Beside token provisioning, link directly to resetting expired tokens.

**Result to check.** A reader stuck at the step can find the matching remedy in one hop.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
