# Status badges

**Use when.** A visible workflow, package, or release signal can substantiate a specific current status.

**Reader task.** Purpose and audience.

**Practice.** Surface meaningful build, release, or license signals and link each badge to its source.

**Example (illustrative).** Show the default branch CI badge and link it to the named workflow.

**Result to check.** Check that the badge's branch and workflow match the claim it labels.
