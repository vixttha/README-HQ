# Progressive disclosure

**Use when.** Optional detail interrupts the core reading path.

**Reader task.** Navigation and accessibility.

**Practice.** Collapse optional details or move them to a clearly labeled supporting document.

**Example (illustrative).** Keep the first-run steps visible and put optional flags in an expandable section.

**Result to check.** Required instructions and navigation remain available with all expandable content closed.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [GitHub collapsed sections](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/organizing-information-with-collapsed-sections)
