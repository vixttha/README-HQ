# Check keyboard navigation on the rendered README

**Use when.** The rendered README has links or controls that readers navigate by keyboard.

**Reader task.** Verification and trust.

**Practice.** Use the keyboard on the published view to reach the primary links and any collapsible controls. Check for visible focus and an order that follows the content. W3C includes these in its preliminary accessibility checks.

**Example (illustrative).** Tab from the README navigation links to the collapsible example and activate it with the keyboard.

**Result to check.** Focus follows the reading order and the controls can be operated without a pointer.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [W3C accessibility checking guide](https://www.w3.org/WAI/test-evaluate/preliminary/)
