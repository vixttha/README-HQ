# Changelog and version navigation

**Use when.** Readers need to link product changes to a specific version.

**Reader task.** Handoff and maintenance.

**Practice.** Show where release history lives and which version the reader is viewing.

**Example (illustrative).** Link the changelog, current releases, and the docs for the previous supported version.

**Result to check.** A reader upgrading from the old version can find the relevant changes.
