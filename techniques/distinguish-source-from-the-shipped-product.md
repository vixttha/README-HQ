# Distinguish source from the shipped product

**Use when.** The source tree and the distributed product have different names, terms, or components.

**Reader task.** Purpose and audience.

**Practice.** Explain what readers are browsing, which product or distribution it produces, and where each set of terms applies. VS Code does this for Code - OSS and Microsoft’s Visual Studio Code distribution.

**Example (illustrative).** This repository builds the open-source editor. The company-branded installer is distributed separately with its own terms.

**Result to check.** A reader can correctly identify which download and license apply.

**Evidence.** Research reference. Run the reader check on the target project before relying on the documented outcome.

**Research references.** [VS Code source and distribution](https://github.com/microsoft/vscode/blob/f26893c248aa2b2ef1f3dba2134d9d1806559186/README.md#L9-L15)
