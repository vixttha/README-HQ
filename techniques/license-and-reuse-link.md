# License and reuse link

**Use when.** Code, documentation, data, or design assets may have distinct terms.

**Reader task.** Handoff and maintenance.

**Practice.** Point to the actual terms and distinguish project assets with different terms.

**Example (illustrative).** Link the license for source code and label separate terms for sample assets.

**Result to check.** A reader can find the applicable source for each material they want to reuse.

**Evidence.** Illustrative practice. Add a project example or test result when this technique is evaluated.
