# Reuse and attribution

The README HQ template has no owner-approved standalone reuse license recorded here. The owner retains the choice of license. Record any proposed reuse of template material and the permission relied on before distribution.

Imported snapshots retain the licenses and attribution in the [source records](history/README.md). A source's license applies to its own material. Source observations in the technique registry cite the original project, commit, and file. Shared learning candidates describe practices in original language. Copying a source's text, media, or code requires a reviewed license or permission record and the attribution that it requires.
